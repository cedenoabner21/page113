# Page113 - Agencia de Desarrollo Web de Alto Impacto

Landing page moderna y de alto rendimiento diseñada para la agencia de desarrollo web Page113. El sitio está enfocado en la conversión de clientes, ofreciendo servicios de desarrollo a medida con un diseño visual futurista.

##  Características Principales
*   **Diseño UI/UX Futurista:** Interfaz oscura con acentos en esmeralda y animaciones fluidas que generan una experiencia inmersiva.
*   **Navegación SPA (Single Page Application):** Transiciones suaves entre secciones sin recargar la página.
*   **Integración con WhatsApp:** Formulario dinámico que redirige al cliente directamente a WhatsApp con un mensaje preformateado.
*   **Optimización SEO & Open Graph:** Metadatos configurados para compartir en redes sociales con vista previa de imagen y descripción.
*   **100% Responsive:** Adaptado para móviles, tablets y monitores ultrawide.

##  Stack Tecnológico
*   **HTML5:** Estructura semántica y accesible.
*   **Tailwind CSS:** Utilizado para un diseño ágil, responsivo y con un sistema de colores personalizado (`slate-950`, `emerald-500`).
*   **JavaScript (Vanilla):** Lógica para el menú móvil, modales, validación de formularios y sistema de navegación.
*   **Optimización Web:** Preload de fuentes e imágenes LCP para mejorar el rendimiento.
