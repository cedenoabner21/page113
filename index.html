El origen de Page113

Page113 no nació en una oficina aburrida ni tras reuniones corporativas. La verdad es que surgió entre risas y la necesidad de tener un proyecto para nuestro trabajo de grado de colegio. Así de simple, creando prototipos de paginas y paginas como tal, nos recomendaron crear nuestra propia pagina web para mostrar y promocionar nuestra habilidad para crear paginas web. Así nacio Page113 como la ves ahora.
